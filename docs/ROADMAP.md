# TrendMill — מפת דרכים ותמונת מצב

> מסמך לבעלים. קוד ותוכן מוצרים באנגלית; המסמך הזה בעברית כי הוא בשבילך.
> רקע אסטרטגי מלא: [RESEARCH.md](RESEARCH.md).

## האסטרטגיה בשורה אחת

מנוע אחד (סריקה → ייצור → אישור → העלאה → למידה) שמריץ **כמה נישות במקביל**
ובהמשך מוזרם לערוצים עם הפצה מובנית (Fiverr) והכנסה חוזרת (SaaS למוכרים).
5 נישות × $40/חודש = $200/חודש פסיבי זה יעד ריאלי; הפוטנציאל האמיתי בשלבים ב'-ד'.

## צ'קליסט הפעלה (הפעולות שלך, ~30 דקות)

1. ⬜ Supabase: פרויקט חדש → להריץ את **כל** קבצי `migrations/` לפי הסדר (001–006).
2. ⬜ BotFather: ליצור בוט, להשיג `TELEGRAM_BOT_TOKEN` ואת ה-chat id שלך.
3. ⬜ למלא `.env` לפי `.env.example` (כולל `TRENDMILL_NICHES`).
4. ⬜ Railway: שירות web + קרון יומי (`23 6 * * *`) + קרון שבועי (`41 6 * * 1`) + קרון חודשי (`19 5 3 * *` ל-foresight) — טבלה ב-README.
5. ⬜ `python scripts/set_webhook.py https://<web>.up.railway.app`
6. ⬜ **Spike**: `GUMROAD_ACCESS_TOKEN=... python spike/gumroad_create_spike.py` →
   לפי ה-VERDICT לקבוע `UPLOAD_STRATEGY=api` או `playwright` (ואז גם
   `GUMROAD_EMAIL/PASSWORD` + התקנת Playwright, ואימות חד-פעמי של הסלקטורים).
7. ⬜ לאשר מוצר ראשון מהדייג'סט ולוודא שהוא עולה חי.

## למה הפלטפורמות שנבחרו (יתרונות מול חלופות)

| החלטה | למה | החלופות שנדחו |
|---|---|---|
| **Gumroad** למכירה | עמלה רק פר-מכירה (10%+$0.50), אין דמי ליסטינג, API למכירות, תומך גם ב-memberships (חשוב לשלב ד') | Etsy: $0.20/ליסטינג + חובת גילוי AI אבל יש לה חיפוש פנימי — **תוספת עתידית**, לא תחליף; Payhip/Lemon Squeezy: עמלות דומות אך בלי יתרון מובהק ובלי ה-API שכבר נכתב |
| **Railway** לתשתית | $5 כולל usage, קרונים מובנים, פריסה מ-repo אחד | VPS: זול אבל תחזוקה; Lambda/Cloud Run: cold starts ומורכבות מיותרת לעומס הזה |
| **Supabase** ל-DB | free tier נדיב, Postgres אמיתי, ORM פשוט | SQLite על Railway: נמחק בדיפלוי; Mongo: אין צורך |
| **Telegram** לאישורים | חינם, כפתורים, קבצים לנייד, webhook | אימייל: איטי; Slack: תשלום |
| **OpenRouter** ל-LLM | החלפת מודלים בשורת env, מחיר DeepSeek לשוטף | קריאה ישירה לספקים: שני SDK-ים במקום אחד |

## שלבי המשך (לפי ההמלצות מהמחקר)

### שלב א' — ייצוב הליבה (עכשיו)
הפריסה + קבלת M1-M3 בעולם האמיתי + שבועיים של ריצה. יעד: 10-20 מוצרים חיים
בשתי נישות, נתוני מכירות ראשונים בלולאת הלמידה.

### שלב ב' — הפצה (המסקנה המרכזית מהמחקר: ההפצה היא צוואר הבקבוק)
- להפעיל Gumroad followers + אימייל מובנה.
- מוצר-פיתיון חינמי ($0+) בכל נישה לבניית רשימה.
- ניוזלטר "הנישות העולות של השבוע" — נבנה מהדאטה שהסורק כבר מייצר, נמכר
  כ-membership ב-Gumroad (בלי Stripe, בלי שירות חדש בתשלום).

### שלב ג' — Fiverr productized service (הפצה מובנית, מחיר ×3-10)
גיג "Custom spreadsheet/dashboard in 24h" ($30-150). המחולל הקיים = מנוע
המילוי; נוסיף צינור: הזמנה → טופס דרישות → spec מותאם → אישור בטלגרם → מסירה.
דורש ממך נוכחות מעט גבוהה יותר בהתחלה (ביקורות ראשונות).

### שלב ד' — הסורק כ-SaaS למוכרי Etsy (הכנסה חוזרת)
בוט טלגרם רב-משתמשים שמוכר את הדייג'סט היומי כמנוי $15-25/חודש, נמכר דרך
Gumroad memberships. דורש: טבלת subscribers, אימות רישיון מול Gumroad API,
הפרדת דייג'סטים פר-לקוח. רוב הקוד — כבר קיים.

### שלב ה' — שוק ישראלי (אופציונלי)
נישת עברית/RTL במחולל + ערוצי הפצה מקומיים (קבוצות פייסבוק).

## חשבון צנוע ליעד שהגדרת

5 נישות פעילות × ~2 מוצרים חיים בשבוע × חודשיים ≈ 80 מוצרים בקטלוג.
גם בהתפלגות הפסימית מהמחקר (רוב המוצרים ~$0, זנב קטן מוכר), קטלוג בגודל כזה
עם לולאת למידה שמכבה מפסידים ומכפילה מנצחים — יעד של $40/נישה/חודש הוא סביר,
והעלות השולית של כל נישה נוספת ~$0. המכפיל האמיתי מגיע משלבים ב'-ד'.
